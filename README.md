# StreamTV

StreamTV est un lecteur IPTV web moderne pour gérer et regarder ses propres playlists autorisées.

## V1
- Next.js + React
- Supabase Auth + base de données sécurisée
- M3U / M3U8
- Xtream Codes prévu dans le flux d'import
- TV en direct, films, séries, recherche et favoris
- Lecteur HTML5
- Interface responsive mobile / desktop

Les playlists et flux doivent être détenus ou utilisés avec l'autorisation nécessaire. StreamTV ne fournit aucune liste IPTV tierce.
